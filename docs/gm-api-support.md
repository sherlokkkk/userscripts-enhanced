# GM API 支持

状态基于当前源码和自动化测试；Safari 扩展真实执行仍待启用验证。**Build 4 用独立 realm + DOM 膜修复 ambient 扩展 API 绕过，JSDOM/WebKit 门禁通过，完整 Safari 安全对抗仍待验。**

| API                                                                                         | 实现/返回语义                                                                    | 边界                                                                                                                                                        |
| ------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GM_registerMenuCommand` / `GM_unregisterMenuCommand`                                       | 同步 ID / undefined；支持 options.id 更新、accessKey、autoClose、title           | 同名不合并；按 frame 分开；clickedFrame 明确报错；每脚本 200 命令；回调事件为合成事件，不能伪造 Safari 用户手势                                             |
| `GM.registerMenuCommand` / `GM.unregisterMenuCommand`                                       | Promise                                                                          | callback 保留在原 frame；后台仅路由地址                                                                                                                     |
| `GM_getValue/setValue/deleteValue/listValues`                                               | 真正同步读取预加载缓存；同步写入先改缓存、排队持久化                             | write-behind 失败会报告并回退；无法同步保证磁盘写入完成；只接受有限数值、字符串、布尔、null、数组、普通 JSON 对象                                           |
| `GM.getValue/setValue/deleteValue/listValues`                                               | Promise；写入等待持久化、失败 reject                                             | 跨标签页通过 storage 事件最终一致；同键最后完成的写入获胜，不提供 CAS/事务                                                                                  |
| `GM_addValueChangeListener/removeValueChangeListener` 及 `GM.*`                             | 同步 listener ID / Promise 形式；含 remote 标志                                  | 删除用带 writer 的 tombstone 通知；注销/页面销毁清理；数据来自同一 scriptId                                                                                 |
| `GM_xmlhttpRequest` / `GM.xmlHttpRequest`                                                   | 同步 abort control / 带 abort 的 Promise                                         | HTTP(S)、GET/HEAD/POST/PUT/PATCH/DELETE/OPTIONS、文本/JSON/二进制/文档、headers/body、超时、终止、读取进度。64 MiB 响应上限；默认 30 秒，最高 300 秒        |
| 网络授权                                                                                    | 原生复核已安装源码 revision、grant、启用状态，再校验 @connect 和 Safari 宿主许可 | 不跟随重定向；拒绝 Cookie/Host/Origin 等受限制头；不支持 upload progress、binary 字符串、HTTP user/password、overrideMimeType。与 Tampermonkey 不是完整等价 |
| `GM_addStyle` / `GM.addStyle`                                                               | style 元素 / Promise<style>                                                      | 使用当前 frame 的 DOM；严格 CSP 的全部行为未实测                                                                                                            |
| `GM_addElement` / `GM.addElement`                                                           | 元素 / Promise<element>；支持 parent、tag、attributes                            | 用户脚本自行创建的 UI，非管理器入口                                                                                                                         |
| `GM_log` / `GM.log`                                                                         | 带脚本名称的 console 输出；GM.log 经 Promise 适配                                | 本地控制台，无遥测                                                                                                                                          |
| `GM_info` / `GM.info`                                                                       | 脚本描述、版本、namespace、原始 metadata、处理器名称/版本                        | 结构沿用原版，部分 Tampermonkey 扩展属性不等价                                                                                                              |
| `GM_openInTab` / `GM.openInTab`                                                             | 同步控制对象 / Promise<control>；close、closed、onclose                          | 仅 HTTP(S)；active/background；不支持 insert/setParent/incognito；无法随意关闭非该脚本创建的标签                                                            |
| `GM_getTab/saveTab/getTabs`                                                                 | callback 形式 / GM.\* Promise 形式                                               | session 存储按 scriptId/tabId 隔离；关闭标签后清理；不是浏览器完整 Tab 对象                                                                                 |
| `GM_setClipboard` / `GM.setClipboard`                                                       | callback 适配 / Promise，失败不报告成功                                          | plain text/HTML，5 MB；Safari 用户手势/权限不足会报错；真实剪贴板行为未验证                                                                                 |
| `GM_getResourceText/GM_getResourceURL` / `GM.getResourceText/getResourceUrl/getResourceURL` | 同步预载资源 / Promise                                                           | UTF-8 文本或 data URL；HTTPS、拒绝重定向；32 资源、合计 8 MB；原生缓存；sha256/384/512 校验；不是 Tampermonkey 的 blob URL 语义                             |
| `@require`                                                                                  | 原有顺序拼接，增强 HTTPS、完整性、缓存和失败阻断                                 | 旧版本依赖缓存保留以支持回滚；HTTP 依赖和跨域重定向不支持                                                                                                   |
| `unsafeWindow`                                                                              | 尚未实现                                                                         | 主世界与特权 API 不能直接混用；不得用暴露 browser 对象的方式伪装实现                                                                                        |
| `GM_notification`、`GM_download`                                                            | 尚未实现                                                                         | 未来可评估原生通知/保存对话框，当前不会返回假成功                                                                                                           |
| `GM_cookie`                                                                                 | 尚未实现                                                                         | 未请求 cookies 权限；Safari 缺少 cookies.onChanged，其他能力仍需单独授权和实现                                                                              |
| `GM_webRequest`                                                                             | 尚未实现                                                                         | Safari 不支持等价 BlockingResponse/阻塞改写；不能声称完整兼容                                                                                               |
| 批量 values、URL change 事件、高级请求管理                                                  | 尚未实现                                                                         | 保留元数据和兼容提示                                                                                                                                        |

示例见 `tests/fixtures/`；精确语义测试见 `tests/value-store.test.js`、`tests/network.test.js`、`tests/tab-api.test.js`、`tests/menu-runtime.test.js`、`tests/engine.test.js`。

Safari 平台事实根据 [Apple API 兼容说明](https://developer.apple.com/documentation/safariservices/assessing-your-safari-web-extension-s-browser-compatibility) 核查；菜单选项参考 [Tampermonkey 官方菜单文档](https://www.tampermonkey.net/documentation.php?q=GM_registerMenuCommand)。上述未实测项仍需按实际 Safari 版本验证。
